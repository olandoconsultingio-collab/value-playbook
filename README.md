# The V.A.L.U.E. Framework

An interactive, single-page web edition of Olando M.'s Business Value Playbook. It translates the complete 20-page framework into a responsive scrolling experience while preserving the original content and beige, olive, terracotta, and black visual system.

## Preview locally

Open `dist/index.html` in a browser, or serve the `dist` directory with any static file server.

## Deployment

The site is a static build ready for Cloudflare Pages. Set the build output directory to `dist`; no build command is required.

Planned custom domain: `value-playbook.olandomarle.com`.
